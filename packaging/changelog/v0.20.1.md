## What's new in 0.20.1

### Fixes
- LinDVB no longer crashes right after tuning a channel ("free(): double free detected in tcache 2" / "malloc(): unaligned tcache chunk detected"). Reading the genre from the programme guide through GStreamer's MPEG-TS library freed memory twice. The guide is now read from the raw stream, so genres from the broadcast guide show up again (#178)
- Tuners whose drivers only report the newer DVB API v5 statistics (e.g. Digital Devices cards with Sony CXD28xx demodulators) show real signal, SNR, BER and error figures instead of random values (#178)
- The virtual tuner (vidtv) is recognised on Linux 7.0 (#174)

### Snap
- Internet TV over HTTPS plays in the snap: it now brings the TLS backend that GStreamer needs (#175)
- HbbTV works in the snap: it now brings WebKitGTK 6 (#177)

### Quality
- `lindvb --self-check` also plays an HTTPS HLS stream and loads a page in WebKit (#175, #177)
