## What's new in 0.14.0

### SAT>IP
- Network tuners: LinDVB receives from SAT>IP servers (SAT>IP boxes and LNBs, minisatip, FRITZ!Box Cable, Octopus NET). Each server tuner works like a local one for live TV, timeshift, recordings, EPG, HbbTV and channel analysis (#93)
- Preferences > Tuners: search the network or add a server by address, with UDP or TCP per server; SAT>IP servers also appear in the channel search (#93)

### Channel search
- Newer transponder lists from Tvheadend's copy of dtv-scan-tables: 5754 tables instead of 3987, including new DVB-T2 lists for Germany, the Netherlands, Italy, Croatia and Poland and new cable lists. They are updated monthly (#90)

### More distributions
- The Flatpak uses the GNOME 51 runtime and now includes the projectM visualisations; the codecs come from the runtime's codecs extension (#91)
- On systems older than the AppImage supports (glibc below 2.39, e.g. Debian 12, Ubuntu 22.04), the AppImage stops with a clear message that points to the Flatpak (#91)
- At start LinDVB checks for GTK 4.10 and the GStreamer plugins it needs, and shows the install command for your distribution when something is missing (#91)
- README: which package fits which distribution (#91)

### Fixes
- projectM: the visualisation fills the whole picture instead of showing a fragment, nothing or garbage on some drivers (#92)
