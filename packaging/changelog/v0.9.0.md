## What's new in 0.9.0

### Several tuners at once
- Preferences ▸ Tuner and Channels lists every tuner found, with its reception types (DVB-S/S2, DVB-C, DVB-T/T2, ...). Each tuner can be switched on or off, gets a priority and can have an LNB of its own (#57)
- A channel only goes to a tuner that can receive it: a satellite channel no longer lands on a cable tuner (#57)
- Channels on the same transponder share one tuner, so a recording and live TV of another channel on that transponder need only one tuner (#57)
- Tuners on one antenna cable (loop-through or a splitter) get the same cable name and then only use one band and polarisation at a time (#57)
- Without any tuner settings, LinDVB now uses every tuner it finds, not only the first one (#57)

### Unicable and JESS
- Single-cable systems: Unicable I (EN 50494, 8 user bands) and Unicable II / JESS (EN 50607, 32 user bands, 64 satellite positions), set per tuner with user band, frequency and an optional PIN, and templates of common devices (#57)
- LinDVB tunes these tuners itself and sends the command again when there is no signal, for when another receiver on the cable sent at the same moment (#57)
- The channel search works on single-cable tuners too (#57)

### Channel analysis
- A new Channel Analysis window (right click on a channel, or the main menu) with seven pages: signal margin, C/N, level and BER curves, error timeline, dish alignment tone, every PID with bit rate and continuity errors, PCR jitter, transponder occupancy, video and audio formats with EBU R 128 loudness, SI tables with a decoded tree and hex view, encryption and HbbTV applications. Internet channels show server, HLS/DASH variants and buffer. It can compare two channels and export the results (#55)

### Other changes
- The LinDVB logo shows faintly in the empty player while nothing plays (#54)
- Releases also contain an Ubuntu/Debian `.deb` and a Python source package (#53)
- README and feature list cleaned up: LinDVB is now described as a digital TV and radio app (#56, #57)
